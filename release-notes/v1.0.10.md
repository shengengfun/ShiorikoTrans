# ShiorikoTrans v1.0.10

修掉「勾选发送到翻译页后，第二次转录不正常」，把模型设置归到转录下，重做关于页；翻译增加了服务状态检测、HuggingFace 镜像和下载速度显示；同时精简了大批说明文案并继续压缩首屏体积。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.10_x64-setup.exe` | **全量版**。内置 ffmpeg，装完即用，体积大一些 |
| Windows | `ShiorikoTrans_1.0.10_x64-setup-slim.exe` | **精简版**。不含 ffmpeg（约 83 MB 下载量省掉），首次转录音频/视频时提示并在应用内下载，也可以自己在设置里手动下载 |
| macOS | `ShiorikoTrans_1.0.10_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.10_amd64.deb` / `ShiorikoTrans-1.0.10-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

两个 Windows 包功能完全一致（引擎、模型、界面都相同），只差 ffmpeg 是否内置。

## 本版改动

### 修复：勾选「转写后转到翻译页」后，第二次转录不正常

两个原因叠在一起：

- 回到转录页时，上次选好的文件被清空了，界面上看起来「什么都没了」；
- 自动跳转只看「有没有转录结果」，重新回到首页时拿**上一次的旧结果**立刻又把人送回翻译页，首页根本待不住。

现在：文件选择**跨页面保留**（切到翻译页、批量页再回来仍在），自动跳转只在**刚跑完一次新转录**时触发。

### 设置

- **模型归到转录下**：原来的「选择模型」独立入口去掉，模型相关设置变成转录分节里的三个子标签（模型目录 / 已安装 / 存储位置），导航少一层。
- **关于页重做**：应用图标与版本、系统与提交号、当前模型 / 引擎 / ffmpeg 来源 / CPU 支持；维护动作（复制诊断信息、复制日志、打开日志目录、临时目录、模型目录、检查更新）；项目链接；重置默认设置与重置应用（两步确认）；许可与致谢。
- **文案瘦身**：删掉 36 条「说明性」设置描述，只保留真正会影响判断的几条（例如「0 = 永不卸载」「强制 CPU 会变慢」）；分节标题下不再挂副标题，外观页的长段落移除。
- **更好用一点**：设置左栏宽度可拖拽调整，分节标签较多时可横向滚动，设置行增加悬停反馈。

### 翻译

- **服务状态可见**：翻译前先探测本地服务是否在监听。以前未启动时只会抛出 `error sending request for url (http://127.0.0.1:8080/v1/chat/completions)`，现在会直接说明「翻译服务未启动」，并给出一条**含绝对路径**的 `llama-server` 启动命令供一键复制；设置里也会显示「服务在线 / 服务未启动」。
- **下载加速**：新增 **HuggingFace 镜像开关**（把 `huggingface.co` 换成 `hf-mirror.com`），识别模型与翻译模型都生效。
- **进度更清楚**：模型下载弹窗现在显示**速度**（MB/s）与**预计剩余时间**，多 GB 的模型不会再像卡住。

### 性能 / 体积

- 设置面板与 Word（docx）导出改为**按需加载**：首屏脚本从 1.77 MB 降到约 1.34 MB（另拆出设置 87 KB、docx 329 KB，只在真正用到时加载）。
- 转录内容没有变化时**不再重复写盘**（之前每次防抖都会整体重写一次存储）。
- 窗口隐藏 / 最小化到托盘时，状态栏停止轮询系统读数，恢复可见时立即刷新。

## 已知问题 / 升级说明

- **翻译的本地引擎需要你自己跑一个服务**：应用负责下载 GGUF 模型并生成启动命令，但不会代为启动 `llama-server`（LM Studio / Jan / vLLM 等同理）。也可在翻译设置里改用 Ollama 或 Claude。
- 精简版首次处理音视频文件需要联网下载 ffmpeg（约 83 MB，一次即可）；全量版无此需求。
- 「最近」的转录内容保存在应用配置目录（`transcripts.json`），最多保留 12 条、约 600 万字符；超出后最旧的记录会保留条目但不再保留内容（列表会标注「仅文件」）。
- Linux 的 deb / rpm 依赖系统 ffmpeg 包（发行版仓库里已有），不区分精简 / 全量；macOS 目前只提供全量 dmg。
- 批量页的转写队列仍是页面级状态，切页会中断队列显示（尚未改造）。
- 上游预编译的 `sona` 二进制不含 SenseVoice 引擎（本仓库构建的 sidecar 含），用 CI 工作流构建的包可能无法使用 SenseVoice，其余模型不受影响。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

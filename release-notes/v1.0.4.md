# ShiorikoTrans v1.0.4

外观主题重做（跟随系统 / 主题色兼容深色），新增「模型目录」一键下载多语言模型，支持 Parakeet / Nemotron / SenseVoice 三种新引擎。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.4_x64-setup.exe` | **推荐**。自带 `sona` 引擎，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_1.0.4_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.4_amd64.deb` / `ShiorikoTrans-1.0.4-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

> 首次启动可直接在欢迎页一键下载推荐模型，之后也可以随时在 **设置 → 模型 → 模型目录** 里补充。

## 本版改动

### 外观 / 主题

- **主题选择移入「个性化 → 外观」**（通用页不再重复提供）。
- 新增 **跟随系统**：可选 跟随系统 / 浅色 / 深色，跟随系统时会随 Windows、macOS 的亮暗切换实时生效（旧版本只有浅色/深色两个选项，升级后自动沿用旧选择）。
- 新增 **外观主题（调色板）**：默认 / 午夜蓝 / 极地 / 暖光 / 墨黑，五套底色与层级色，**浅色与深色各自成套**。
- **深色模式现在与主题色完全兼容**：调色板只改「底色/层级色」，主题色（预设 9 色 + 任意自定义色号）单独叠加，切换深浅色时自动取用该主题色对应的深色变体，所有按钮、选中态、圆环、图表色都保持一致。
- 修掉几处只在浅色下好看的颜色（模型列表的引擎标签等），现在都走主题变量。

### 模型目录（一键下载）

**设置 → 模型 → 模型目录** 新增精选模型列表，点「下载」即自动放进模型目录并选中，下载过程有进度条；欢迎页（首次启动）也直接列出推荐模型。

| 模型 | 引擎 | 大小 | 语言 |
| --- | --- | --- | --- |
| Parakeet TDT 0.6B v3 (Q4_K_M) | parakeet | 463 MB | 25 种欧洲语言 |
| Nemotron 3.5 ASR Streaming 0.6B (Q4_K_M) | nemotron | 473 MB | 32 种语言（含中/日/韩/阿/印地/越/俄…） |
| SenseVoice Small (int8) | sensevoice | 229 MB | 中文 / 英文 / 粤语 / 日语 / 韩语 |
| Whisper Large v3 Turbo (Q5_0 / F16) | whisper | 547 MB / 1.5 GB | 99 种语言 |
| Whisper Large v3 / Medium / Small / Base / Tiny | whisper | 2.9 GB / 514 MB / 181 MB / 57 MB / 31 MB | 99 种语言 |

- **新增引擎支持**：Parakeet TDT（0.6B，TDT 解码，速度很快）、Nemotron 3.5 ASR Streaming（RNNT，32 语言流式结构）、SenseVoice Small（CTC ONNX，中/英/粤/日/韩，极快）。
- Parakeet / Nemotron 需要 VAD 辅助模型：**会自动下载**（约 1 MB）再开始转写，不需要手动准备。
- SenseVoice 需要 `model.int8.onnx` + `tokens.txt` 两个文件，目录式安装由应用自动完成。
- 模型设置的「引擎能力」菜单已适配新引擎：不支持翻译 / 提示词 / 词级时间戳的项会置灰并说明，Parakeet / Nemotron 会提示需要 VAD。
- 目录式模型的引擎识别更准确（`models/transcribe/<模型名>/model.int8.onnx` 这类以文件夹定名）。
- `docs/models.md` 里的下载链接修正为**公开可用的仓库**（之前指向的私有/占位仓库会 401）。

## 已知问题 / 升级说明

- 安装包体积因 **ONNX Runtime 运行时**（`onnxruntime.dll` / `DirectML.dll` / `onnxruntime_providers_shared.dll`，约 38 MB，SenseVoice 引擎需要）而增加：Windows 安装包约 42 MB → 约 57 MB。
- SenseVoice 引擎由仓库内 `sona` 源码构建的 sidecar 提供；上游预编译的 sona 二进制不含该引擎，因此用 CI 工作流构建的包可能无法使用 SenseVoice（其余模型不受影响）。
- 批量页的转写队列仍是页面级状态，切页会中断队列显示（与上一版相同，尚未改造）。
- 自定义背景图片仍按旧逻辑叠加遮罩；若与「墨黑」等深色主题搭配觉得偏暗，可先移除背景图。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

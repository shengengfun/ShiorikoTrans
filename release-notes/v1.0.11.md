# ShiorikoTrans v1.0.11

这一版解决「本地翻译到底能不能用」：**应用自己下载并运行本地模型**，不用再手动安装 llama.cpp、也不用复制启动命令。总结页也重做完成，可以用同一个本地小模型给转录文本生成总结。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.11_x64-setup.exe` | **全量版**。内置 ffmpeg，装完即用，体积大一些 |
| Windows | `ShiorikoTrans_1.0.11_x64-setup-slim.exe` | **精简版**。不含 ffmpeg（约 83 MB 下载量省掉），首次转录音频/视频时提示并在应用内下载，也可以自己在设置里手动下载 |
| macOS | `ShiorikoTrans_1.0.11_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.11_amd64.deb` / `ShiorikoTrans-1.0.11-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

两个 Windows 包功能完全一致（引擎、模型、界面都相同），只差 ffmpeg 是否内置。

## 本版改动

### 本地模型开箱可用（翻译 / 总结共用）

以前「本地翻译」只负责下载模型文件，服务要你自己开——没开就会抛 `error sending request for url (http://127.0.0.1:8080/v1/chat/completions)`。现在：

- 应用在需要时**自动下载 llama.cpp 运行时**（约 70 MB，一次性），并按你的 CPU 选择合适版本；
- **翻译或总结时自动启动服务**，用完不打扰，退出应用时自动关闭；
- 设置里能看到运行状态（运行时是否就绪 / 服务是否运行 / 端口），也可以手动启动、停止；
- 默认模型换成约 **1 GB 的小模型**（Qwen3 1.7B），首次体验不用等 4 GB 下载；想要质量可以随时换成 Hunyuan-MT-7B 等更大的模型；
- LM Studio / Jan / vLLM / Ollama / OpenAI / Claude 仍然照常可用。

### 总结页重做

- 转录完成后点「**总结**」即可生成总结；设置里还可以让它**转录完成后自动打开总结页**；
- 总结页签现在**没有总结也能进入**，空状态里直接放「总结 / 总结设置」入口；
- **长转录不再失败**：文本较长时自动分段总结、再合并成一份完整总结，小模型也能处理两小时录音；
- 设置 → 总结里可以调整：**提示词预设**（默认摘要 / 精简摘要 / 要点清单 / 会议纪要 / 学习笔记）、**恢复默认提示词**、分块字数、温度、以及生成总结用的本地模型。

### 修复

- 提示词里如果没有 `%s`，以前会**把转录文本整段丢掉**，现在会自动附加在提示词后；
- 设置里的「测试连接 / 运行检查」会先自动启动本地服务，不再误报连接失败。

### 设置

- 新增「转录完成后打开翻译页 / 打开总结页」两个开关（设置 → 通用 → 完成时）；
- 本地模型列表在翻译和总结两处共用：下载、切换、或直接从磁盘选择一个 `.gguf` 文件。

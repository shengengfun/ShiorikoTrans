# ShiorikoTrans v1.0.3

修掉「转录到一半切页就丢进度」的老毛病，顶栏模型选择显示完整模型名，模型参数搬进独立窗口，设置通用页重做。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.3_x64-setup.exe` | **推荐**。自带 `sona` 引擎，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_1.0.3_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.3_amd64.deb` / `ShiorikoTrans-1.0.3-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

> 首次转写前请在 **设置 → 模型** 里下载一个识别模型（推荐 **Large v3 Turbo**）。

## 本版改动

### 修复

- **转录进度不再丢失**：转写会话（进度、已出分段、摘要、录音状态）移到路由之上的全局会话层。
  现在开关设置、切到「批量 / 翻译」页再回来，进度条和已转出的文字都还在，转录完成的结果也不会被丢掉。
  回到转录页时会自动恢复正在转写的那份文件。
- 转写进行中关闭窗口的二次确认，现在在任何页面都生效（此前只在转录页生效）。

### 模型

- **顶栏「选择模型」显示完整模型名**：目录式模型（`models/transcribe/<模型名>/xxx.bin`）显示模型名，
  文件名以等宽小字作为副标题（此前只显示 `model.bin` 这类文件名）。
- **模型设置独立窗口**：标题栏模型下拉里每个模型右侧新增齿轮按钮，设置 → 模型 里也新增「模型设置」入口。
  菜单按引擎类型自动切换：
  - Whisper / 自定义：线程、温度、最大文本上下文、最大句长、采样策略、初始提示词、翻译目标、词级时间戳、说话人分离、稳定时间戳
  - Nemotron：线程、温度、说话人分离、模型内存
  - SenseVoice / Hunyuan：无解码参数（明确提示），只保留模型内存等通用项
  - 能力不支持的项目会置灰并给出说明
- 目录式模型的引擎识别改为先看模型名再退回文件名（此前 `model.bin` 会被当成「自定义模型」，导致设置项显示错误）。

### 设置

- **通用页重做**：界面语言、主题（浅色/深色）、完成后提示音与自动聚焦、录音保存位置与默认导出格式
  （转录 / 摘要各一份，可选 txt / srt / vtt / json / csv / docx / md / pdf / html）、最近文件与最近语言清理、
  一键恢复默认选项。
- **移除隐私页**：其中的匿名统计开关与隐私政策链接一并删除。若需要关闭匿名统计，可在应用配置目录的 `store` 文件里把
  `analytics_enabled` 设为 `false`（读取逻辑仍在，只是不再提供界面开关）。
- **移除设置里的「型号选项」与「微调」页**，相关内容全部并入模型设置窗口；模型内存（空闲卸载）也一并移过去。
- 清理了两个已经没人引用的旧组件（旧模型参数弹窗与其入口按钮）。

## 已知问题 / 升级说明

- 批量页的转写队列仍是页面级状态，切页会中断队列显示（下一次推进会一并改造）。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_X.Y.Z_x64-setup.exe` | **推荐**。自带 `sona` 引擎，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_X.Y.Z_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_X.Y.Z_amd64.deb` / `ShiorikoTrans-X.Y.Z-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

> 首次转写前请在 **设置 → 模型** 里下载一个识别模型（推荐 **Large v3 Turbo**）。

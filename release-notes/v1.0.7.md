# ShiorikoTrans v1.0.7

修复转录结果保存失败与转录时窗口卡死，并把「翻译」做成真正独立、可离线运行的一整套：本地小模型一键下载 + 页内切换模型 + 完成提示音。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.7_x64-setup.exe` | **推荐**。自带 `sona` 引擎与 ONNX Runtime，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_1.0.7_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.7_amd64.deb` / `ShiorikoTrans-1.0.7-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

## 本版改动

### 修复

- **修复转录结果保存不出内容**：文本区的内容是按防抖重建的，转录进行中或刚结束时点保存，写到磁盘的可能是上一次的内容甚至空文件。现在保存时会以当前转录段落**实时重建**目标格式（`txt / srt / vtt / json / csv`），只要原文还在，保存出来的文件就一定完整。
- **修复源文件丢失后无法保存**：从转录页切走再切回来，选中文件被清空，点保存会直接报错。现在源文件未知时也会用 `transcript.<格式>` 作为默认文件名打开保存对话框。
- **修复转录时窗口无法最小化 / 整体卡顿**：随转录不断到来的每个分段事件都会触发整棵界面重渲染，文本区还会为每个分段重建整篇文稿（长文件是 O(n²)），把 UI 线程占满，而窗口的 最小化 / 最大化 / 关闭 都是网页按钮，于是全部失灵。现在：
  - Rust 侧进度上报只在**整数百分比变化**时发事件（原先每个音频块都发一次）；
  - 前端把分段事件**批量合并**（120ms 一批）后再进状态；
  - 文本区文稿重建改为**150ms 防抖**。

### 翻译（本次重点）

- **「设置 → 翻译」正式独立成页**：开关、引擎、端点、模型、默认目标语言、每次请求行数、温度、最大 Tokens 全都在这里，与转录摘要的 LLM 配置**完全互不影响**。
- **默认引擎改为「本地模型（OpenAI 兼容服务）」**，不再默认指向 Ollama。指向本机任意 OpenAI 兼容服务即可：llama.cpp `llama-server`、LM Studio、Jan、vLLM（提供一键预设：`127.0.0.1:8080 / 1234 / 1337 / 8000`）。Ollama 与 Claude 仍可选。
- **内置本地翻译模型目录，一键下载**（全部为公开可直连的 GGUF）：
  | 模型 | 量化 | 体积 | 语言 |
  | --- | --- | --- | --- |
  | **Hunyuan-MT-7B**（翻译专用，推荐） | Q4_K_M / Q3_K_M | 4.3 GB / 3.5 GB | 38 |
  | Qwen3 1.7B | Q4_K_M | 1.0 GB | 100+ |
  | Qwen2.5 3B Instruct | Q4_K_M | 2.0 GB | 29 |
  | Qwen3 4B | Q4_K_M | 2.3 GB | 100+ |
  | Gemma 3 4B IT | Q4_K_M | 2.3 GB | 140 |

  下载完成后可直接复制「启动命令」（形如 `llama-server -m "<模型路径>" --port 8080 --host 127.0.0.1`）在本地起服务，**不需要 Ollama**。
- **翻译页内嵌模型选择器**：下拉里只列出已下载的本地模型，切换即写入翻译配置；旁边齿轮直接跳到「设置 → 翻译」。工具栏下方会显示当前引擎（本机端点会高亮为「本地模型」）与目标语言。
- **长文本按行分块翻译**：原本一次性把整段文本丢给模型，长转录必然被截断；现在按行分组（默认 25 行一批，可在设置里改 1–100），空行原样保留、**行数不变**（字幕时间轴不会错位），并实时显示百分比进度。
- **翻译完成提示音**：翻译结束后播放完成音，可在「设置 → 翻译」或「设置 → 通用 → 完成时」关闭。
- 转录页的「翻译」按钮也改走翻译专用配置，转录完成后长转录会分块翻译并保留时间轴。

### 其他

- 设置侧边栏的「翻译 / 外观」标签改为跟随界面语言，不再是写死的中文 / 英文。

## 已知问题 / 升级说明

- 本地翻译需要你自己起一个 OpenAI 兼容服务（应用内提供模型下载与启动命令，但不捆绑 `llama-server` 二进制）。
- 安装包含 ONNX Runtime（`onnxruntime.dll` / `DirectML.dll`）用于 SenseVoice 引擎，因此体积约 57 MB。
- 上游预编译的 `sona` 二进制不含 SenseVoice 引擎（本仓库构建的 sidecar 含），用 CI 工作流构建的包可能无法使用 SenseVoice，其余模型不受影响。
- 批量页的转写队列仍是页面级状态，切页会中断队列显示（尚未改造）。
- 已有的翻译配置不会被覆盖：升级后如果仍指向 Ollama，请到「设置 → 翻译」把引擎切到「本地模型（OpenAI 兼容服务）」。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

# ShiorikoTrans v1.0.8

彻底修掉「转录时窗口卡住」，把发言者选项放回设置里并默认不再加 `[发言者 1]` 前缀，新增**精简版安装包**（ffmpeg 改为按需下载），图标换成与 RinaDown 一致的圆角样式。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.8_x64-setup.exe` | **全量版**。内置 ffmpeg，装完即用，体积大一些 |
| Windows | `ShiorikoTrans_1.0.8_x64-setup-slim.exe` | **精简版**。不含 ffmpeg（约 83 MB 下载量省掉），首次转录音频/视频时提示并在应用内下载，也可以自己在设置里手动下载 |
| macOS | `ShiorikoTrans_1.0.8_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.8_amd64.deb` / `ShiorikoTrans-1.0.8-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

两个 Windows 包功能完全一致（引擎、模型、界面都相同），只差 ffmpeg 是否内置。

## 本版改动

### 修复：转录时窗口卡住（本次重点）

真正的原因不在界面，而在**主线程被系统监控读数堵住**：状态栏每 1.2 秒调用一次 `get_system_stats`，而这是个同步命令，Tauri 的同步命令跑在**主线程**上；`sysinfo` 采集 CPU 占用是一次阻塞调用（它要等采样间隔过去才能算出差值）。于是转录期间每秒都会把窗口事件循环堵住一段，而窗口的最小化 / 最大化 / 关闭是本应用自己用网页画的按钮 —— 表现就是「点最小化没反应 / 整个窗口像卡死」。

现在：

- CPU / 内存改为**后台线程每秒采样**，命令只读缓存快照，主线程零阻塞。
- `sona` 推理进程降为**低于正常优先级**：转录满载时优先保证界面响应，代价只是吞吐略降。
- （承接上一版）进度事件只在整数百分比变化时上报，分段事件 120ms 批量合并，文稿重建 150ms 防抖。

### 发言者（说话人）选项

- **选项回来了**：「设置 → 转录」新增「发言者与时间戳」卡片 —— 说话人分离、**显示发言者标签**、稳定时间戳三个开关都在这里，不再只藏在单个模型的设置窗口里（模型窗口里也保留了这几个开关）。
- **修复每句前面都出现 `[发言者 1]`**：引擎在没有开启说话人分离时也会返回发言者编号（全部是 1），旧逻辑只判断编号存在与否，于是每行都加前缀。现在前缀**由开关决定，默认关闭**；打开说话人分离时会自动把标签打开，关闭分离也不会再强行加前缀。该规则覆盖转录文本、HTML 预览、`txt / srt / vtt / docx` 导出、批量页、听写热键与摘要提示词。

### 精简版安装包（ffmpeg 改为按需下载）

- 安装包中最大的单个文件就是 `ffmpeg.exe`（未压缩 97 MB / 静态构建 83 MB），现在**可以不打包**：
  - `tauri.slim.conf.json` 定义精简包的打包清单（不含 ffmpeg），`pnpm build:windows` / `pnpm build:windows:slim` 分别产出全量版与精简版。
  - 应用启动时把「应用数据目录」注册进 ffmpeg 查找链，因此**内置 / 已下载 / 系统 PATH** 三种来源都能被自动识别。
  - 「设置 → 转录 → 运行时依赖」会显示当前 ffmpeg 状态（内置 / 已下载 / 系统安装 / 未安装）与实际路径，并提供「下载 ffmpeg」按钮（带进度弹窗）。
  - 精简版下首次转录音频/视频时，会先询问是否立即下载 ffmpeg，下载完成后自动重启推理进程使其生效。
  - 下载源为公开的 `eugeneware/ffmpeg-static` 单文件构建，无需解压；也可自行安装 ffmpeg 或放进 PATH。
- CI 在发布 Windows 全量包之后会再构建并上传精简包。

### 图标

- 全部图标（Windows 任务栏、安装包、macOS、Linux、Android、Windows Store）改为**圆角方形**，与工作区里 RinaDown 的图标风格一致（内缩约 5.8%、圆角约 19%，四角透明）。
- 新增 `plans/app-icons/app-icons_002.py`：从 `logo.jpg` 生成圆角母图 `design/logo_rounded.png` 及遗留尺寸/设计资源，之后 `tauri icon design/logo_rounded.png` 生成标准图标集（含 `.ico` / `.icns`），一条链路可完整复现。

## 已知问题 / 升级说明

- 精简版首次处理音视频文件需要联网下载 ffmpeg（约 83 MB，一次即可）；全量版无此需求。
- Linux 的 deb / rpm 依赖系统 ffmpeg 包（发行版仓库里已有），不区分精简 / 全量；macOS 目前只提供全量 dmg。
- 批量页的转写队列仍是页面级状态，切页会中断队列显示（尚未改造）。
- 上游预编译的 `sona` 二进制不含 SenseVoice 引擎（本仓库构建的 sidecar 含），用 CI 工作流构建的包可能无法使用 SenseVoice，其余模型不受影响。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

# ShiorikoTrans v1.0.12

这一版把**翻译**做成真正开箱可用：内置离线翻译模型，不需要任何配置；同时修好了无边框窗口拖不动、以及启动后内容要手动拉一下窗口才铺满的问题。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.12_x64-setup.exe` | **全量版**。内置 ffmpeg，装完即用，体积大一些 |
| Windows | `ShiorikoTrans_1.0.12_x64-setup-slim.exe` | **精简版**。不含 ffmpeg（约 83 MB 下载量省掉），首次转录音频/视频时提示并在应用内下载，也可以自己在设置里手动下载 |
| macOS | `ShiorikoTrans_1.0.12_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.12_amd64.deb` / `ShiorikoTrans-1.0.12-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

两个 Windows 包功能完全一致，只差 ffmpeg 是否内置。

## 本版改动

### 翻译：内置离线模型，打开就能用

翻译不再需要你准备任何「服务」——不需要安装 llama.cpp、不需要填接口地址或 API Key：

- 内置**翻译专用模型 NLLB-200**（200 种语言），和应用一起在本机运行，**完全离线**；
- 首次使用点一下「下载模型」即可（约 1.36 GB，一次性），之后翻译全程不联网；
- 引擎选项简化为：**内置翻译模型（离线，无需配置）**、Ollama、Claude，以及给需要接自建服务的人保留的「OpenAI 兼容端点（高级）」；
- 翻译页新增**源语言**选择（默认自动识别），并保留原有的双语对照、并排对照与保存；
- 之前配置过本地 llama.cpp 的用户会自动切换到内置模型，不影响继续使用总结功能。

### 修复

- **无边框窗口拖不动**：窗口的最小化 / 最大化按钮之前点了没反应，现在都能用；标题栏任意空白处（含图标与标题文字）都可以拖动窗口，双击标题栏可最大化/还原；
- **启动后内容不铺满**：以前窗口打开后要手动拉一下边框，界面才会完整显示，现在启动即为完整尺寸。

### 界面

- 转录页右侧的文本窗口高度与左侧设置区域**自动等高**，两个底边对齐，不再出现一高一矮；
- 整体字体略微缩小（约 6%），中文标签与说明文字的显示更完整。

## 已知问题 / 升级说明

- 内置翻译模型首次使用需下载约 1.36 GB，之后无网络也可翻译；下载失败时会自动改用镜像站重试。
- 小语种、口语化很强的台词，机器翻译质量有限，可在设置里改用 Ollama / Claude 等引擎。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

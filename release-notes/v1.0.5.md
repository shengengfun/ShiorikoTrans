# ShiorikoTrans v1.0.5

模型目录按类型分组展开、主题色换成虹咲 13 色并补上自定义调色滑条，多模型兼容彻底打通（Home / 批量 / 听写三条路径共用一套引擎能力表）。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.5_x64-setup.exe` | **推荐**。自带 `sona` 引擎与 ONNX Runtime，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_1.0.5_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.5_amd64.deb` / `ShiorikoTrans-1.0.5-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

## 本版改动

### 外观 / 主题

- **主题色换回 13 个虹咲角色应援色**（步梦 / 霞 / 雫 / 果林 / 爱 / 彼方 / 雪菜 / 艾玛 / 璃奈 / **栞子** / 米娅 / 岚珠 / 侑），**默认仍是三船栞子 `#37B484`**，纯色块 + 选中打勾。
- **自定义色补上调色滑条**：色相（彩虹条）/ 饱和度 / 明度 三条滑块 + 颜色预览 + `#` 十六进制输入（回车或失焦生效），滑条滑块会显示当前颜色。
- 主题色改动即时生效，并自动推导深色变体；浅色系（如霞的黄色）会自动切换成深色前景文字，保证按钮文字对比度。
- 主题调色板卡片改成「小窗预览」：底色 + 卡片 + 主题色圆点 + 分隔线，一眼看出深浅色下的实际效果。
- 主题模式（跟随系统 / 浅色 / 深色）与外观主题（默认 / 午夜蓝 / 极地 / 暖光 / 墨黑）保持上一版行为。

### 模型目录

- **改成按类型分组**：NVIDIA NeMo（Parakeet / Nemotron）、Whisper、SenseVoice 三组，点标题展开后再挑具体型号与量化档（Q4_K_M / Q5_0 / Q8_0 / F16 / int8 …），每组带引擎标签、语言数与已安装状态。
- 新增 Parakeet / Nemotron 的 Q8_0 档位。

### 多模型兼容（本次实质修复）

- 引擎能力改成**声明式注册表**（`lib/model-pipeline.ts`）：每种引擎声明支持哪些参数（提示词 / 温度 / 采样 / 最大文本上下文 / 词级时间戳 / 翻译 / VAD / 说话人分离），模型设置窗口的菜单直接由它生成。
- **修复：模型参数不再被无差别下发**。之前切到 Nemotron / Parakeet / SenseVoice 时，仍然带着 Whisper 时代的提示词与翻译目标，sona 会直接报错（`does not support text prompts` / `does not support translation`）导致转录失败；现在按引擎自动剔除，翻译目标在不支持时自动归零。
- **三条转录路径共用同一个选项构建器**（`lib/transcribe-options.ts`）：转录页、批量页、全局听写热键。VAD 辅助模型（Parakeet / Nemotron 必需）缺失时自动下载，不再需要手动准备。
- 批量页与听写热键也会随模型能力自动附带 VAD / 跳过不支持的参数。

## 已知问题 / 升级说明

- 安装包含 ONNX Runtime（`onnxruntime.dll` / `DirectML.dll`，约 38 MB 未压缩）用于 SenseVoice 引擎，因此体积约 57 MB。
- 上游预编译的 `sona` 二进制不含 SenseVoice 引擎（本仓库构建的 sidecar 含），用 CI 工作流构建的包可能无法使用 SenseVoice，其余模型不受影响。
- 批量页的转写队列仍是页面级状态，切页会中断队列显示（尚未改造）。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →「打开」即可。

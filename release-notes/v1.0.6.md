# ShiorikoTrans v1.0.6

翻译工作区升级为独立模型配置与双视图编辑，并新增覆盖转录与翻译结果的全局搜索替换。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `ShiorikoTrans_1.0.6_x64-setup.exe` | **推荐**。自带 `sona` 引擎与 ONNX Runtime，自动创建开始菜单与桌面快捷方式 |
| macOS | `ShiorikoTrans_1.0.6_<arch>.dmg` | 打开后把 App 拖进 Applications |
| Linux | `ShiorikoTrans_1.0.6_amd64.deb` / `ShiorikoTrans-1.0.6-1.x86_64.rpm` | Debian / Ubuntu、Fedora / RHEL |

## 本版改动

### 翻译

- 翻译页现在使用**独立的翻译模型配置**：在“设置 → 翻译”中分别设置平台、模型、端点和 API Key，不会影响转录摘要的 LLM 配置。
- 新增两种翻译显示模式：**原文译文对照**保留双文本框，并实现等高与同步滚动；**双语对照**在单个文本框内按原文、译文交替显示。
- 移除翻译页多余的“翻译 / Translation”标题，扩大编辑区域；翻译内容和视图模式会在切换页面后保留。

### 全局搜索

- 顶栏 Recent 左侧新增搜索按钮，可搜索转录原文、转录译文、摘要以及翻译页原文和译文。
- `Ctrl/Cmd+F` 打开搜索，`Ctrl/Cmd+H` 打开替换；支持一键替换所有匹配文本。

### 本地化

- 中文界面的 “Transcription” 统一显示为“转录”。

## 已知问题 / 升级说明

- 双语对照按文本行配对显示；对于经过模型大幅重排段落的译文，建议使用“原文译文对照”模式逐段编辑。
- macOS 包未签名 / 未公证，首次打开若被 Gatekeeper 拦，右键 →“打开”即可。
